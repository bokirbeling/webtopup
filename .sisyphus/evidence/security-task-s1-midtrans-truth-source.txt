# S1 Midtrans Truth Source Evidence

Implemented hardening in `backend/src/modules/payment/payment.service.ts`.

Checks added before payment/order mutation:

- Midtrans signature must be valid.
- Webhook event is deduplicated by provider/event key.
- `gross_amount` must match stored order/payment amount.
- Existing paid payment cannot be downgraded by later failed/expired webhook.
- Paid webhook cannot mark an already failed/expired order as paid.
- Failed verification updates webhook event state to `failed` where an event was registered.
