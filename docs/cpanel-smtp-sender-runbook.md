# cPanel SMTP Sender Setup for Adnanpay Email Verification

This runbook configures one sender mailbox for application email. Adnanpay users and resellers remain application database records; do not create a cPanel mailbox per user or reseller.

## Sender Mailbox

1. In cPanel, open Email Accounts.
2. Create or select one sender mailbox, for example `no-reply@adnanpay.com`.
3. Store the generated mailbox password only in the deployment environment, never in Git, docs, tickets, or screenshots.
4. Use cPanel's email client configuration page to confirm the SMTP host, port, and TLS mode.

## Backend Environment Placeholders

Set these environment variables in the backend runtime only:

```env
SMTP_HOST=mail.adnanpay.com
SMTP_PORT=465
SMTP_USER=no-reply@adnanpay.com
SMTP_PASSWORD=<cPanel mailbox password from the server secret store>
SMTP_FROM_EMAIL=no-reply@adnanpay.com
SMTP_FROM_NAME=Adnanpay
```

Use port `465` for implicit TLS when cPanel lists it. If the host only provides STARTTLS, use the cPanel-provided port instead. Keep `SMTP_FROM_EMAIL` aligned with the authenticated mailbox so SPF/DKIM/DMARC checks pass.

## Operational Checks

- Confirm DNS SPF, DKIM, and DMARC are enabled in cPanel Email Deliverability.
- Send only verification email from this mailbox; product users do not get mailbox accounts.
- Rotate `SMTP_PASSWORD` if it is exposed, then update the backend runtime secret and restart the app.
- Keep custom JWT auth as the source of truth; SMTP only delivers the verification secret generated by the backend.

## Admin and Reseller Login Boundary

- Admin login happens in Adnanpay (`/admin`) with application JWT, not with cPanel email credentials.
- Reseller login happens in Adnanpay (`/dashboard`) with application JWT, not with cPanel email credentials.
- cPanel mailbox access is only for the sender account such as `no-reply@adnanpay.com`.
- Do not create a mailbox for every admin, member, or reseller.
- If a reseller cannot request activation, check `email_verified_at` in the application user record and resend verification from the app flow.
