# Product Assets

Asset lokal untuk gambar produk/kategori Adnanpay.

Aturan:
- Nama file singkat berbasis produk/kategori.
- Dipakai oleh frontend dengan path `/product-assets/<file>`.
- Di UI semua gambar dipaksa rasio sama (`object-cover`) agar desktop/mobile rapi.
- Source mentah/audit ada di `docs/reference-assets/` dan tidak perlu dipush jika hanya referensi.
